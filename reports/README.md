# Milestone Reports

Each `RPT-####.md` begins as a draft instantiated from [`templates/report.md`](../templates/report.md) and becomes an immutable human-facing snapshot when published. It links the strongest results, counterexamples, experiments, literature, direction outlook, manuscript progress, and consequential decisions.

[`OVERVIEW.md`](../OVERVIEW.md) remains the mutable navigation page. Reports do not replace the operational resume state or authoritative evidence. Correct a material report error by creating a superseding report rather than silently rewriting history.
