# Experiments

Each experiment lives in `EXP-####/` and begins with a README instantiated from [`templates/experiment.md`](../templates/experiment.md). Keep reusable infrastructure separate from question-specific code and derived outputs.

Completed executions are append-only and use experiment-local monotonic IDs. Preserve commands, dependencies, inputs, source-data provenance, parameters, seeds, relevant hardware, outputs, and integrity digests where practical. Empirical success is not a mathematical proof.
