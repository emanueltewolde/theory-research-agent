# Research Runs

Each substantial session receives `RUN-####/RUN.md`, created from [`templates/run.md`](../templates/run.md), plus optional focused task directories:

```text
RUN-####/
├── RUN.md
└── tasks/
    └── T01/
        ├── TASK.md
        ├── OUTPUT.md
        └── RECEIPT.md
```

The run record is chronological history and a concise handoff. It is not the authoritative home for exact claims or evidence. Integrate important findings into durable artifacts, then update `STATE.md` last.
