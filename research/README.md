# Durable Research Records

This directory contains the direction portfolio, deferred inbox, exact claims, attempts (including negative results), and independent reviews.

- [`DIRECTIONS.md`](DIRECTIONS.md) is authoritative for direction activity and assessment.
- [`INBOX.md`](INBOX.md) is the shared deferred-item intake and triage record.
- [`claims/`](claims/) stores exact epistemic statements.
- [`attempts/`](attempts/) stores what was tried and why it succeeded, failed, or remains unresolved.
- [`reviews/`](reviews/) stores fresh independent verification.
- [`directions/`](directions/) stores optional long expansions whose compact status remains in the portfolio.

Use the artifact contracts in [`docs/ARTIFACTS.md`](../docs/ARTIFACTS.md). Do not treat a task output or run log as a substitute for a durable claim or attempt.
