# Claims

Each `CLM-####.md` states exactly one theorem, lemma, counterexample, impossibility, empirical observation, or literature-derived proposition using [`templates/claim.md`](../../templates/claim.md).

Claim status and evidence class are distinct. “Validated” means validated relative to the stated evidence class. A computational or empirical result is not thereby a mathematical proof. Reviews bind to the current claim revision and normalized statement digest.
